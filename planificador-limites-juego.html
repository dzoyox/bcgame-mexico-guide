El plan y el temporizador funcionan solo en este navegador. No se crea una cuenta ni se envían datos.

El límite no es una meta de gasto. Es un máximo que no debe superarse. No aumentes el límite para recuperar pérdidas y no uses dinero reservado para vivienda, comida, facturas, ahorro o deudas.

Cuándo conviene no iniciar la sesión

  • Quieres recuperar dinero perdido anteriormente.
  • Te sentirías obligado a ocultar el gasto o el tiempo dedicado.
  • Necesitas pedir dinero, usar crédito o posponer una factura.
  • Estás alterado, bajo efectos de alcohol u otras sustancias o no puedes aceptar perder el importe completo.
