Qué significa el resultado

COINCIDE

El compromiso es consistente

El seed revelado genera exactamente el hash publicado. Eso indica que ese valor no fue cambiado después del compromiso.

NO COINCIDE

Los datos no son los mismos

Revisa espacios, caracteres y que el hash pertenezca a esa ronda o rotación. Si sigue sin coincidir, conserva capturas y contacta al soporte oficial.

Esto no verifica por sí solo el resultado de la apuesta. Cada juego puede combinar server seed, client seed y nonce con un algoritmo distinto. La herramienta solo comprueba el compromiso SHA-256 del server seed.

Qué sí y qué no demuestra

  • Sí: que el seed revelado coincide con el hash SHA-256 que guardaste antes.
  • No: que el resultado completo de la ronda se haya transformado correctamente.
  • No: una devolución concreta, ausencia de house edge, solvencia, licencia o rapidez de retiro.
  • No: la posibilidad de predecir la siguiente ronda.

Proceso correcto

  1. Guarda el hash del server seed antes de jugar.
  2. Espera a que el operador revele o rote el server seed.
  3. Compara aquí el seed revelado con el hash guardado.
  4. Para reproducir la ronda, usa además el algoritmo oficial específico del juego, client seed y nonce.
